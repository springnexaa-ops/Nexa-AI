# NEXA Medical Model Evaluation

Evaluation is a release gate, not an afterthought.

## Evaluation layers

- General language quality
- Medical knowledge accuracy
- Evidence attribution
- Hallucination resistance
- Clinical safety
- Privacy leakage
- Bias/fairness
- Neurophysiology signal performance
- Calibration/uncertainty
- Robustness
- Regression testing

## Neurophysiology metrics

Future EEG/EP evaluations should include sensitivity, specificity, AUROC/AUPRC where appropriate, false-positive rate, event localization error, latency and performance versus real-time.

Clinical claims require appropriate expert review and validation before deployment.
