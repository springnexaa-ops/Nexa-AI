# Security Baseline

Never commit credentials, tokens, private keys, certificates, or personal/clinical data. Use least-privilege secrets, HTTPS/TLS, secure cookies, input validation, parameterized queries, authentication/RBAC, rate limiting, CSRF protection where applicable, security headers, encryption, protected backups, dependency scanning, logging/monitoring and incident response.

For EMR/neuro/LMIS systems, never use identifiable production data in source code, tests, CI logs, screenshots or public AI prompts. Engineering baseline only; not a legal certification.
