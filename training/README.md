# NEXA Foundation Training

Training code and configurations for the proprietary NEXA model program.

## Rules

- Never train on unapproved or identifiable patient data.
- Use versioned dataset manifests.
- Keep train/validation/test identities separated.
- Record dataset, code, tokenizer, configuration and base-model lineage for every run.
- Produce evaluation artifacts before a model can be promoted.
- Do not claim proprietary training where only inference or fine-tuning has occurred.

## Planned stages

1. Medical text/knowledge representation
2. Medical language adaptation
3. Neurophysiology signal learning
4. Multimodal alignment
5. Safety and clinical evaluation
