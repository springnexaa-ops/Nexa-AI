# NEXA Clinical Validation Plan

## Objective
Demonstrate that each intended medical function performs safely and reproducibly for its defined use case, users and population.

## Validation package
1. Define intended use, clinical question, target users and patient population.
2. Freeze the software/model/evidence versions under test.
3. Define reference-standard labels or expert adjudication criteria.
4. Pre-specify endpoints and acceptance thresholds appropriate to the use case.
5. Evaluate sensitivity, specificity, PPV/NPV or other task-appropriate metrics.
6. Measure calibration/uncertainty where probabilistic output is used.
7. Evaluate clinically important failure modes and false positives/negatives.
8. Assess subgroup performance and potential bias where applicable.
9. Conduct usability and human-oversight evaluation.
10. Document deviations, limitations, statistical analysis and final conclusions.
11. Repeat validation after material model, retrieval, workflow or intended-use changes.

## Release principle
A successful technical test is not equivalent to clinical validation. Production clinical claims should be limited to functions supported by controlled validation evidence.
