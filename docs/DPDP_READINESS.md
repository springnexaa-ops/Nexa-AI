# DPDP Readiness Baseline

For India DPDP Act 2023 / DPDP Rules 2025 readiness: purpose limitation; data minimisation; clear notice/consent where applicable; access/correction/erasure/grievance workflows; access controls and encryption; retention/deletion controls; processor governance; incident response; child-data safeguards where applicable; privacy-by-design.

Maintain a data inventory, processing-purpose register, data-flow map, retention schedule, processor register, access matrix and incident-response plan. Treat healthcare/clinical data as high-risk operationally. Never put identifiable records in Git or CI logs.

Legal note: technical readiness checklist only; not legal advice or a compliance certification.
